# Developer Reflection
One thing I learned while making my Job & Internship Application Tracker was how the search and status filter work together. An application does have to match both what the user searches and the status they choose to show up. Having AI break down the code helped me understand what each part does and how it connects to what appears on the page.
I used AI to start off and get my ideas going. For example, AI would help me find where to make changes, but I still had to decide what made sense for my tracker. I chose the colors, descriptions, status options, and which information should be required or optional. These choices came from what I would want when keeping track of my own applications.
I also got more comfortable going through my code and making changes myself. I used code from previous projects and had AI help me figure out how to fit it into this one. My biggest takeaway was that I need to review and understand the changes AI suggests so I can explain how my tracker works and keep updating it myself.
