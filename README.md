# About 
    I created this website to keep all job and internship applications together. Most of peers are either applying to internships or worrying about post-grad jobs. This is an organized place, so there is no need to forget what the position was or dealines. This also reminds you to follow up or to actually hit submit on the application. 

# Features 
    - add, edit, delete applications 
    - save links, contacts, notes, follow-up dates
    - update application statuses
    - search by company or position and filter by status 
    - see labels for upcoming deadlines
    - switch between light and dark themes 

# How to Use
    1. Click Add Application 
    2. Enter information (nothing private)
    3. Click Save application 
    4. Go to Saved Applications to search, update, edit, or delete application 

    Applications are saved in browser you are using. They will not transfer with devices.
